# Show Password for Flarum

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/huseyinfiliz/show-password.svg)](https://packagist.org/packages/huseyinfiliz/show-password) [![Total Downloads](https://img.shields.io/packagist/dt/huseyinfiliz/show-password.svg)](https://packagist.org/packages/huseyinfiliz/show-password)

A [Flarum](http://flarum.org) extension. Toggle password visibility on login and signup modals.

## Features

- Eye icon toggle on password fields
- Works on both **LogIn** and **SignUp** modals
- Adds proper `autocomplete` attributes for better browser support

## Requirements

- Flarum `^1.8.0`
- PHP `^8.1`

## Installation

Install with Composer:

```sh
composer require huseyinfiliz/show-password:"*"
```

## Updating

```sh
composer update huseyinfiliz/show-password
php flarum cache:clear
```
